# Amal Roy — Portfolio

Personal portfolio built with React + Vite. Animated pieces (Aurora background, split-text reveal, spotlight cards, count-up stats, logo loop, click sparks) are modelled on [React Bits](https://reactbits.dev).

## Run locally

```bash
npm install
npm run dev
```

## Edit content

All text lives in `src/data.js` — projects, skills, education, certifications, links and tagline.

## Update the resume

Replace `public/Amal_Roy_Resume.pdf` with the new PDF (keep the same file name).

## Deploy

1. Push this folder to a GitHub repo.
2. Import the repo at vercel.com/new — Vercel detects Vite automatically.
3. To use a custom domain later: Vercel project → Settings → Domains → Add.
